# Regulatory Compliance Review — 서비스 자체의 규제 준수 검토

법령 정보를 제공하거나 법률 관련 기능을 제공하는 서비스 자체가 변호사법 등 관련 법규를 위반하지
않는지 검토한다. "이 서비스가 제공하는 것"이 단순 정보 제공인지 법률사무 취급(자문)인지의 경계를
다룬다.

## 1. 핵심 판단 기준 — 변호사법 제109조

(2026-08-17 `korean-law-mcp`로 원문 대조해 확인 — 법령은 개정되므로 실제 검토 시점에
`korean-law-lookup`으로 재확인할 것)

변호사가 아닌 자가 **금품·향응 등 이익을 받고** 다음에 해당하는 법률사무를 취급·알선하면 처벌 대상이다:

- 소송·비송·가사 조정/심판 사건
- 행정심판·이의신청 등 불복 사건
- 수사·조사 기관 취급 사건
- 그 밖의 일반 법률사건에 대한 감정·대리·중재·화해·청탁·법률상담·법률 관계 문서 작성

**핵심은 "유상성"과 "개별 사안에 대한 법률사무 취급"이다.** 법령 원문을 그대로 보여주거나 일반적인
법률 정보를 제공하는 것과, 특정 사용자의 구체적 사안에 대해 자문·대리·문서작성을 유상으로 제공하는
것은 다르다 — 후자로 갈수록 리스크가 커진다.

## 2. 스크리닝 체크리스트

| 질문 | 리스크가 커지는 답 |
| :--- | :--- |
| 서비스가 특정 사용자의 구체적 사안에 답하는가, 일반 정보만 제공하는가? | 구체적 사안에 답할수록 리스크 큼 |
| 유상 서비스인가? | 유상일수록 리스크 큼(제109조가 이익 수수를 요건으로 함) |
| 서비스가 "법률 자문"·"법률 대리" 같은 표현을 쓰는가? | 그런 표현을 쓸수록 리스크 큼(오인 소지) |
| AI 생성 답변이 실제 변호사 검토 없이 최종 결론처럼 제시되는가? | 그렇다면 리스크 큼 |
| 사용자가 그 답변을 근거로 법적 행동(소송, 계약 체결 등)을 할 가능성이 있는가? | 가능성이 클수록 리스크 큼 |

## 3. 리스크 완화 방향 (일반적으로 통용되는 접근 — 확정적 법적 조언이 아님)

- 일반적인 법령 정보 제공에 그치고, 개별 사안 자문처럼 보이지 않게 서비스 UX를 설계한다.
- "법률 자문이 아니다"라는 고지를 명확히 표시한다(단, 고지만으로 실질적 법률사무 취급이 자동 면책되는
  것은 아니라는 점도 함께 인지한다).
- 무상·광고 목적 정보 제공과 유상 개인 맞춤 자문을 서비스 구조상 분리한다.

## 출력 형식

판단 근거(체크리스트 답변) → 리스크 수준(상/중/하, 정성적 판단이며 확정 아님) → 완화 방향 제안 →
"실제 변호사 확인 필요" 고지.

## 에러 핸들링

- 이 스킬은 결론("괜찮다"/"안 된다")을 내리지 않는다 — 항상 리스크 수준과 근거만 제시하고 실제
  변호사 확인을 권한다.
- 유사 서비스의 실제 규제 대응 사례는 공개된 자료에서 찾을 수 있으면 인용하고, 못 찾으면 "사례 확인
  안 됨"으로 표시한다.

## 제약

- 법률 자문을 대체하지 않는다.
- 금융 규제(투자자문업 등)는 이 스킬의 범위 밖이다 — `investment-regulatory-review`를 쓴다.
