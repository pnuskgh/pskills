# 검색엔진별 사이트 등록 상세 절차

등록 URL과 UI는 각 서비스가 자주 개편한다 — 여기 적힌 절차의 "순서와 원칙"은 유지되지만, 실제 진행
시점에는 웹 검색으로 현재 URL을 다시 확인한다. 오래된 URL을 그대로 안내하지 않는다.

## Google 서치콘솔 (Google Search Console)

- **속성 유형 선택**: 두 가지 중 하나
  - **도메인 속성**: DNS TXT 레코드로 소유확인. 서브도메인·프로토콜(http/https) 전체를 한 번에
    포함하지만, DNS 접근 권한이 있어야 하고 전파에 15분~4시간 걸린다.
  - **URL 접두어 속성**: HTML 파일 업로드 / `<meta>` 태그 / Google Analytics / Google Tag Manager
    중 선택. HTML 파일·메타태그는 보통 몇 분 내 확인되지만, 배포·테마 교체 시 태그가 사라지면
    소유확인이 풀릴 수 있다 — 코드베이스에 영구적으로 남도록 삽입한다(빌드 시 제거되지 않는 위치).
- **선택 기준**: DNS 접근 권한이 있으면 도메인 속성이 더 안정적이다(서브도메인 전체 커버, 코드
  변경과 무관). DNS 접근이 어렵거나 사이트 코드만 건드릴 수 있으면 메타태그 방식을 쓴다.
- **등록 후**: `sitemap.xml` 경로를 서치콘솔의 "Sitemaps" 메뉴에 제출한다.

## 네이버 서치어드바이저

1. **소유확인**: HTML 태그 방식(`<meta>` 태그를 `<head>`에 삽입) 또는 HTML 파일 업로드 방식 중 선택.
2. **RSS 제출**: 소유확인 후 RSS 피드를 등록한다(블로그/뉴스형 콘텐츠가 있는 경우 색인 속도에 도움).
3. **사이트맵 제출**: 좌측 메뉴 "요청 > 사이트맵 제출"에서 `{도메인}/sitemap.xml`을 등록한다.
4. **순서가 중요하다**: 소유확인 → RSS 제출 → 사이트맵 제출 순서를 지킨다. 사이트맵만 먼저 제출하고
   RSS를 건너뛰면 콘텐츠형 페이지의 색인이 느려진다.
- 색인까지 통상 1~4주 소요된다 — 이 기간 내 미노출은 정상 범위로 안내한다.

## Daum(카카오) 검색등록

- 다음 웹마스터 도구는 카카오 검색 체계로 통합되면서, 일반 사용자가 쓰는 별도 콘솔형 도구가 아니라
  **심사 기반 등록 신청 폼**으로 축소되어 있다 — 서치콘솔/서치어드바이저처럼 실시간 대시보드를
  기대하면 안 된다.
- 등록 절차 개요
  1. 검색등록 페이지에서 "신규 등록하기" → 사이트 검색 선택 → 도메인 입력(`https://` 제외, 도메인만)
  2. 개인정보 수집·이용 동의
  3. 공통 정보(사이트명, 카테고리 등) + 신청자 정보 입력
  4. 제출 후 **최대 5영업일 내 심사** 완료, 통과 시 검색 결과 반영
- **반려 주의사항**: 신청서에 적은 사이트명/카테고리/대표 URL이 실제 사이트와 일치하지 않으면
  반려되거나 원치 않는 카테고리로 등록될 수 있다 — 제출 전 사용자와 이 세 항목을 맞춰 확인한다.
- 다음(Daum)에 등록하면 네이트(Nate) 검색에도 동일하게 노출된다 — 네이트를 별도로 등록할 필요는
  없다.

## Bing 웹마스터 도구 (Bing Webmaster Tools)

- **Google 서치콘솔에서 Import**하는 방법이 가장 빠르다: Bing 웹마스터 도구 로그인 → "Import" →
  Google 계정 연동 허용 → 가져올 속성 선택. 소유확인이 자동으로 완료되고 사이트맵도 함께 넘어온다.
- Bing은 이후 주기적으로 서치콘솔 연동 상태를 재확인한다 — 서치콘솔 접근 권한이 해제되면 Bing 쪽
  소유확인도 끊길 수 있으므로, 별도 수동 인증(메타태그/XML 파일)으로 이중화해두는 것도 고려할 수
  있다.
- Google 등록이 안 되어 있다면 Bing 자체 메타태그/XML 파일/DNS 방식으로 개별 소유확인도 가능하다.

## 등록 순서 권장

1. Google 서치콘솔 (URL 접두어 또는 도메인 속성, 소유확인)
2. Bing 웹마스터 도구 (Google에서 Import — 별도 소유확인 불필요)
3. 네이버 서치어드바이저 (소유확인 → RSS → 사이트맵)
4. Daum 검색등록 (신청 폼 제출, 최대 5영업일 심사 대기)

Google을 가장 먼저 하는 이유는 Bing이 그 결과를 재사용할 수 있어서다 — 순서를 바꾸면 Bing에서
소유확인을 한 번 더 해야 한다.
